# Expense Tracker

A web-based Expense Tracker application built using Python, Flask, SQLite, HTML, CSS, JavaScript, and Chart.js.

## Features

- Add income and expense records
- Edit and delete transactions
- Track total income, expenses, and balance
- Search and filter transactions
- Visualize financial data using charts
- Store data in SQLite database

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

## Project Purpose

This project helps users manage and track their daily income and expenses through a simple and user-friendly interface.
